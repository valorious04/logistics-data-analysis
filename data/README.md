# Data

The repository includes a small synthetic `sample_orders.csv` file so the pipeline can be demonstrated without downloading a large dataset.

For the public Olist Brazilian E-Commerce dataset, download the CSV files from Kaggle or another legitimate public source and place them in `data/olist/`.

Expected files:
- olist_orders_dataset.csv
- olist_order_items_dataset.csv
- olist_products_dataset.csv
- olist_customers_dataset.csv
- olist_sellers_dataset.csv
- olist_order_reviews_dataset.csv
- olist_geolocation_dataset.csv
- olist_order_payments_dataset.csv
- product_category_name_translation.csv

Large external datasets are intentionally not committed to GitHub.
